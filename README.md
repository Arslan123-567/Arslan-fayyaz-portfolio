## 4. JavaScript Functionality

The main JavaScript file is:

`assets/js/script.js`

It controls the interactive behavior of the website.

**Theme Switching**

The `setTheme()` function switches between dark and light themes and stores the selected preference in LocalStorage.

**Sticky Navigation**

A scroll event listener detects when the visitor scrolls beyond 30 pixels and applies a fixed header class.

**Back to Top**

The back-to-top button appears after scrolling beyond 400 pixels. The `scrollToTop()` function returns the visitor to the top.

**Scroll Animations**

AOS initializes scroll-based animations using HTML attributes such as `data-aos` and `data-aos-delay`.

**Testimonial Carousel**

jQuery initializes Owl Carousel to display testimonials with responsive item counts, automatic playback, and navigation.
