# Arslan Fayyaz | Full Stack Developer

Personal portfolio website for Arslan Fayyaz, built with HTML, CSS, JavaScript, and Bootstrap.

## Deploy

This repository deploys automatically to GitHub Pages whenever changes are pushed to the `main` branch.

After the first push, enable GitHub Pages in the repository settings and select **GitHub Actions** as the build and deployment source.

## Local preview

Open `index.html` in a browser, or serve this folder with a local static web server.
